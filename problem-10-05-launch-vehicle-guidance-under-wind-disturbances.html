Mission scenario

Vertical launch through a wind-shear layer

A two-dimensional educational launch vehicle ascends with a single engine and pitch-axis thrust-vector control (TVC). Horizontal wind changes the air-relative flow, creating drag and a lateral aerodynamic force. Compare open-loop ascent to outer-loop position guidance with an inner-loop pitch controller.

Model scope: This is a simplified point-mass-plus-pitch educational model. It uses a linearized lateral aerodynamic force, an approximate pitch moment, exponential atmosphere, fixed inertial vertical reference, and constant thrust/Isp. It is not a flight-qualified design or a realistic orbital insertion guidance law.

Coordinates and sign conventions

Inertial x points horizontally downwind; z is upward. Positive pitch tilts the vehicle thrust direction toward +x. Positive gimbal angle increases the thrust-direction angle. Wind velocity is positive along +x. The aerodynamic lateral force acts to reduce cross-flow, with a sign determined by the relative airflow.

Mathematical model

Governing dynamics and control laws

\(\rho(z)=\rho_0e^{-z/H},\quad w(z)=w_0+w_s\exp[-(z-z_s)^2/(2\sigma_s^2)]\)
\(\mathbf v_a=[v_x-w(z),v_z]^T,\quad q=\tfrac12\rho\|\mathbf v_a\|^2\)
\(\dot m=-T/(I_{sp}g_0),\quad \dot x=v_x,\quad\dot z=v_z\)
\(m\dot{\mathbf v}=T[\sin(\theta+\delta),\cos(\theta+\delta)]^T+\mathbf F_a-[0,mg(z)]^T\)
\(\dot\theta=\omega,\quad I_{yy}\dot\omega=Tl_g\sin\delta+M_a\)
\(\theta_c=\mathrm{sat}[-K_xx-K_vv_x],\quad\delta_c=\mathrm{sat}[K_{p\theta}(\theta_c-\theta)-K_{d\theta}\omega]\)

For a positive upward speed, define the air-relative flow angle \(\gamma_a=\mathrm{atan2}(v_x-w,v_z)\), and angle of attack \(\alpha=\theta-\gamma_a\). A simplified aerodynamic side-force model uses \(F_N=-qAC_{N\alpha}\alpha\), acting perpendicular to the relative velocity, with an approximate restoring aerodynamic moment \(M_a=-qAC_{m\alpha}l_{ref}\alpha\). Axial drag is \(-qAC_D\hat{\mathbf v}_a\). These approximations are used consistently in the simulator.

Engine gimbal response is first order: \(\dot\delta=(\delta_c-\delta)/\tau_g\), with physical saturation. Gravitational acceleration decreases with altitude according to \(g(z)=g_0[R_E/(R_E+z)]^2\).

Implementation

Python and MATLAB starter implementations

The snippets illustrate the wind and relative-airflow model used in the browser simulation. The full coupled simulation is implemented in JavaScript in this standalone page.

Python

import numpy as np
rho0, H = 1.225, 8500.0

def atmosphere(z):
    return rho0 * np.exp(-max(z, 0.0) / H)

def wind(z, w0=8.0, ws=22.0, zs=7000.0, sigma=2000.0):
    return w0 + ws * np.exp(-0.5*((z-zs)/sigma)**2)

def air_relative(vx, vz, z):
    va = np.array([vx - wind(z), vz])
    q = 0.5 * atmosphere(z) * np.dot(va, va)
    return va, q

print(air_relative(0.0, 400.0, 7000.0))

MATLAB

rho0 = 1.225; H = 8500;

rho = rho0*exp(-max(z,0)/H);

va = [vx-w; vz];
q = 0.5*rho*(va.'*va);
fprintf('Dynamic pressure: %.2f Pa\n',q);
Engineering takeaway: Wind-disturbance rejection is a multi-objective guidance problem. Lateral trajectory accuracy, aerodynamic loading, actuator authority, and numerical reliability must be evaluated together.
